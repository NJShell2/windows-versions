Windows Version Numbers

A quick reference of Windows version numbers for client and server, with current builds and end-of-support dates. Last updated: 8 Nov 2026. Updated monthly from Microsoft Learn.

Why this page exists: the long-running reference at techthoughts.info/windows-version-numbers was last updated 1 Dec 2021. It stops at Windows 11 22H2, lists no Windows 11 23H2, 24H2, 25H2, 26H1 or 26H2, no Windows Server 2025, and predates the end of Windows 10 support on 14 Oct 2025. This page is the same idea, kept current.

Right now, in short

  • Windows 11, latest: 26H2, build 26300, latest build 26300.9818 (28 Oct 2026). Home and Pro supported to 10 Oct 2028.
  • Windows 11 24H2 Home and Pro: updates ended 13 Oct 2026. Move to 25H2 or 26H2.
  • Windows 11 23H2 Enterprise and Education: end 10 Nov 2026.
  • Windows 10: support ended 14 Oct 2025. Last version was 22H2, build 19045.
  • Windows Server, current LTSC: Server 2025, build 26100, latest 26100.33674 (26 Oct 2026).

Checking your Windows version

Press Win + R, type winver and press Enter. It shows the version (for example 26H2) and the OS build.

For the full version number in PowerShell:

Get-ItemProperty 'HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion' | Select-Object DisplayVersion, CurrentBuildNumber, UBR

The full number is major.minor.build.revision, for example 10.0.26300.9818 for Windows 11 26H2 with the 28 Oct 2026 update.
